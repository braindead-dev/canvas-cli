# Documentation

Start with [setup](getting-started.md), then choose a guide by task.

- [Coursework](coursework.md): assignments, deadlines, submissions, grades, feedback, modules.
- [Content and files](content.md): pages, files, downloads/uploads, local snapshots, exports.
- [Communication](communication.md): Inbox, discussions, peer reviews, activity.
- [Account and access](account.md): profile, preferences, rosters, groups, invitations.
- [Planning](planning.md): tasks, calendar events, checkboxes.
- [Safety](safety.md): shared privacy and execution rules.
- [Development](development.md): architecture, tests, contributions, validation.
- [Capabilities](../CAPABILITIES.md): coverage and remaining work.

These guides explain behavior and limits, not every flag combination. The parser is the source of truth for exact syntax.

```sh
canvas-pocket help --format brief
canvas-pocket help --search upload --format brief
canvas-pocket help upload-context --format brief
canvas-pocket schema upload-context
```
